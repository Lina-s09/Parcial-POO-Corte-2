INTENCIÓN DEL PROYECTO:
En el desarrollo de este proyecto se busca realizar una aplicación que contenga una Interfaz Gráfica (GUI), Sobre un programa que almacene la información de Pokemones y entrenadores, en una especie de base de datos de tipo CSV.
El cual debe de contener, los requerimientos básicos como:

  -Commists
  
  -Planeación
  
  -Sustentación

  Para el desarrollo de este proyecto decidimos organizar las clases en paquetes que definían su utilidad. Donde en Models se hallaban las clases que contenían los objetos principales, como los jugadores y pokemones, junto a los tipos de pokemones y de más.
  Mientras que en operaciones estaba todo el desarrollo de las funciones principales del archivo que almacenaba el registro de los jugadores y pokemones, cada uno en uno distinto. 
  Finalmente la parte de la Interfaz Gráfica, que permitía ejecutar y visualizar lo hecho en una ventana emergente.
